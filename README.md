# Aug-AFRAD preparation

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24089742.svg)](https://doi.org/10.5281/zenodo.24089742)

Preparation materials for Aug-AFRAD, derived from the [AFRAD magnetic tile dataset](https://wangh257.github.io/AFRAD/data_download.html) ([Wang et al., 2025](https://doi.org/10.1016/j.measurement.2025.116702)).

- Augmentation scripts
- 79 hand-drawn defect masks (47 crack, 32 folds)
- Screening records for 47 label conflicts and 28 multi-defect images

AFRAD images and their augmented derivatives are not included. Redistribution permission has not been obtained. The train/validation/test split is also not part of this release.
