# Aug-AFRAD preparation

Preparation materials for Aug-AFRAD, derived from the [AFRAD magnetic tile dataset](https://wangh257.github.io/AFRAD/data_download.html) ([Wang et al., 2025](https://doi.org/10.1016/j.measurement.2025.116702)).

- Augmentation scripts
- 79 hand-drawn defect masks (47 crack, 32 fold)
- Screening records for 47 label conflicts and 28 multi-defect images

AFRAD images and their augmented derivatives are excluded because redistribution permission has not been obtained. The final train, validation, and test split is outside the scope of this release.
